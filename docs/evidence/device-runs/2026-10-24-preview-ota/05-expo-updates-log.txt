NOTE ON THE LAST BLOCK. "No update available" on the second launch is correct and expected: the
device has already downloaded the latest bundle, so there is nothing newer to fetch. The proof that
the downloaded bundle is the one RUNNING is the offline screen in
`03-offline-launch-still-signed-in.png`, which only the new JavaScript can produce.
